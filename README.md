🚀 CodeArena | Developer Platform
CodeArena ek advanced developer ecosystem hai jo developers ko code karne, collaborate karne aur problem solve karne ke liye ek behtareen platform provide karta hai.
🌐 Live Demo
✨ Features
🎮 Live Coding Arena
Ek interactive environment jahan developers real-time mein code likh sakte hain aur use execute kar sakte hain. Piston engine ki madad se multiple programming languages ka support maujood hai.
👥 Community Hub
Yahan developers ek doosre ke saath connect kar sakte hain aur baat-cheet kar sakte hain. Yeh ek aisa space hai jaha log apne ideas share karte hain aur mil kar grow karte hain.
🔄 Problem Page & Code Converter
Is section mein aap kisi bhi problem ka solution JavaScript ya kisi aur language mein likh kar, usey foran doosri programming languages mein convert kar sakte hain. Programming hurdles ko door karne ka yeh sab se fast tareeka hai.
🤖 AI Assistance
Platform ke andar built-in AI assistant jo aapko debugging, code explanation, aur optimized logic likhne mein madad karta hai.
🛠️ Tech Stack
Frontend: React.js, TanStack Query, DaisyUI (Tailwind CSS)
Backend: Node.js, Express.js
Database: MongoDB
Authentication: Clerk
Real-time & Workflows: Stream, Inngest
Code Execution: Piston API
