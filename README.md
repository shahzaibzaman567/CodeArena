# CodeArena
# Live Collaborative Coding Platform 🚀

A real-time collaborative web application where users can **meet live, write code together, communicate via audio/video, chat instantly, and get AI assistance** — all in one place. Built to support **multiple programming languages** with a smooth, interactive, and developer‑friendly experience.

---

## ✨ Key Features

* 🔴 **Live Collaborative Code Editor**

  * Multiple users can write and edit code together in real time
  * Supports multiple programming languages

* 🎥 **Live Audio & Video Calling**

  * One‑to‑one or group calls
  * Ideal for pair programming and interviews

* 🖥️ **Screen Sharing & Recording**

  * Share your screen during sessions
  * Record coding sessions for later review

* 💬 **Real‑Time Chat & Messaging**

  * Instant messaging alongside live coding
  * Useful for discussion and quick feedback

* 🤖 **AI Coding Assistance**

  * Get help while coding
  * Code suggestions, explanations, and debugging support

* 👥 **Multi‑User Rooms**

  * Join or create rooms to collaborate
  * Perfect for teams, mentors, and students

---

## 🧠 Use Cases

* Remote pair programming
* Coding interviews
* Team collaboration
* Practice coding with friends

---

## 🛠️ Tech Stack (Planned / Used)

* **Frontend:** React (Vite)
* **Backend:** Node.js, Express
* **Real‑Time Communication:** WebSockets / WebRTC
* **Database:** MongoDB (or any NoSQL/SQL as needed)
* **Authentication:** JWT / Sessions
* **AI Integration:** Custom AI assistant
